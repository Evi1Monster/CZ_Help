# CZ Help 1.4.3

修复部分电脑因临时目录路径格式不同，启动时提示 `StatusPath must be a normalized absolute file path.` 的问题。

## 使用

1. 退出辅助和游戏，将完整压缩包解压到新目录。需要保留设置时，复制旧目录的 `CZ_Help.ini`。
2. 打开 `CZ_Help.exe`，等待“准备就绪”后启动游戏。首次识别路径时若游戏已运行，按提示退出游戏完成配置。
3. F8 开关透视，F9 开关方框，F11 开关 HP；F3 开关跳跃辅助，开启后按住空格。

1.4.2 用户也可在退出辅助和游戏后，只替换 `scripts/Session.ps1`。
