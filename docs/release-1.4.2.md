# CZ Help 1.4.2

新增：先启动零点行动，再打开辅助，自动识别游戏所在目录，无需手动修改 INI。面板显示目录，识别成功后自动保存，后续可直接先开辅助。

## 使用

1. 完整解压压缩包，保留 scripts、bin 和 third_party 目录。
2. 启动 Steam《零点行动》普通 BOT 游戏，再打开根目录 CZ_Help.exe。面板下方显示“自动识别”及游戏路径。
3. 首次配置或游戏尚未加载当前插件时，按提示退出游戏，等待“准备就绪 · 等待游戏启动”，再点击“启动本地游戏”。自动识别不增加运行中首次加载插件的能力。
4. F8 开关透视，F9 开关方框，F11 开关变色 HP 数字；F3 开关跳跃辅助，开启后按住空格。跳跃仍只有自动跳跃和 BHopJump 两种模式。
5. 关闭辅助停止功能并自动清理；游戏仍在运行时，后台等待游戏退出再恢复文件。

## 识别规则

- 手动启动参数 `--game-path "目录"` 优先，其次为运行中的零点行动，最后为 INI 配置。
- 根据 hl.exe 的实际进程路径、`-game czero` 参数和零点行动文件确认目录，支持中文、空格和不同 Steam 库位置。
- 多个目录同时运行时优先选择配置匹配项，否则提示指定目录。不会静默选取任意一个安装。
- 无游戏进程时使用保存的目录。查询超过 3 秒、结果不完整或运行权限不足时提示并回退配置，不使用部分结果改写保存的目录。
- 辅助运行期间不会更换已选目录。目录文本框只读，可选中并复制。

本版保留 1.4.1 的透视、跳跃和插件安装/恢复实现；仅更新主程序的目录识别及显示。BHopJump 的实际游玩手感仍以实机验收为准。

验证包括路径优先级、中文目录、CS 1.6 排除、多目录歧义、不完整查询回退，以及临时测试 hl.exe 先启动后由真实辅助识别、保存路径、等待退出、配置和清理的完整流程。实机游玩不属于本轮自动化测试；发布包校验及测试结果见压缩包旁的 CZ_Help-1.4.2-verification.txt。
