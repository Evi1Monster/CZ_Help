# CZ Help 1.3.0 使用说明

本版把插件配置与清理整合进软件，适用于 Steam《CS 零点行动》普通单机 BOT 对战。

## 直接运行

1. **完整解压 ZIP** 到固定目录，退出旧版辅助。
2. 双击根目录 **CZ_Help.exe**。软件自动配置，完成后显示 **准备就绪 · 等待游戏启动**。
3. 点击 **启动本地游戏**，进入 BOT 对局并加入队伍。也可自行启动游戏。
4. 关闭辅助即可停止功能并安排自动清理。

不需要手动执行安装或卸载脚本。请保留同目录的 `bin`、`scripts` 和 `third_party`，不要只复制 EXE。

## 退出与清理

- 游戏已退出：自动恢复配置，删除本软件安装的插件文件。
- 游戏仍在运行：辅助功能立即停止，隐藏清理进程等待游戏退出后完成，随后自行退出。
- 首次启动或需要更新时游戏已打开：显示“等待游戏退出后自动配置”。退出游戏后会自动继续，准备好后再启动游戏。
- 上次清理尚在等待游戏退出时重新打开辅助：新实例等待旧清理完成，然后自动准备。
- 辅助崩溃时执行同样的清理。系统中断导致的可识别残留，会在下次启动恢复。

程序不会终止用户游戏，也不会创建服务或开机启动任务。若检测到安装后的文件被自行修改，会保留它和恢复记录，并显示错误；不会把冲突当成清理成功。

## 功能与按键

| 操作 | 默认按键 |
| --- | --- |
| 连跳开关，开启后按住空格 | F3 |
| 透视总开关 | F8 |
| 方框开关 | F9 |
| 血量数字开关 | F11 |

连跳与透视每次启动默认关闭，支持复选框操作。HP 只有随血量变色的数字，没有血条。全屏 / 窗口 OpenGL 绘制保持原逻辑。

本地对局需 `sv_lan 1`、只有一名真人、存活且第一人称。连跳使用默认 `SPACE +jump` 绑定；松开空格停止，保留原游戏物理。连跳实际画面与客户端预测手感仍需实际游玩复核。

## 设置与排查

默认路径是 `D:\SteamLibrary\steamapps\common\Half-Life`。其他路径在 EXE 旁的 `CZ_Help.ini` 中填写 `[Game]` 的 `Path`，修改后重启辅助。可以点击“编辑设置”；快捷键修改后点击“重新加载设置”。

命令行示例：`CZ_Help.exe --game-path "D:\YourLibrary\Half-Life" --launch-game`。加 `--windowed` 可强制窗口化。

自动配置失败时界面显示原因。权限不足时，应将发布包放在可写目录，并确认游戏目录可写。恢复记录位于游戏内 `czero\addons\cz_help\install-state.json`；有冲突时请保留，成功清理会自动删除。

`scripts\Uninstall.ps1` 是额外的恢复入口，正常使用无需运行它；手动恢复前退出辅助和游戏。源码与验证范围见 `source` 目录和 `source\docs\verification.md`。
