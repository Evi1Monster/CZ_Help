# 1.3.0 自动配置与清理

用户要求运行软件自动准备插件、显示准备就绪或等待游戏启动，退出后自动恢复和清理；随后明确要求继续并先发布这一版。新增跳跃模式属于后续版本，不混入本版。

- 完整解压后直接运行根目录 CZ_Help.exe，无需手动执行安装脚本。游戏目录沿用已确认的 Half-Life 路径，可在 INI 或 --game-path 参数中指定。
- Win32 界面启动隐藏的短期 PowerShell 会话管理进程，复用已有安装备份及白名单。状态为正在配置、准备就绪/等待游戏启动、等待游戏退出、清理中或具体错误。
- 游戏运行且已安装完全匹配的插件时可直接连接；插件缺失或版本不匹配时等待游戏退出再配置，不能写已加载 DLL。
- 关闭界面立即发布功能关闭。管理进程以 PID 和创建时间确认界面退出或崩溃，等待所选游戏进程退出后恢复原配置并删除自己安装的文件。不会终止用户游戏，不使用服务、计划任务或开机常驻。
- 每个游戏目录由独立命名互斥锁管理整个会话。上一清理进程还在等待游戏退出时，新实例等待其完成，避免旧清理拆掉新会话。
- 旧 1.2.0 安装沿用最初 Original 备份。中断恢复允许每个文件处于已安装或已还原状态；未知修改被保留，并明确报错，不能声称清理成功。
- 新增“启动本地游戏”按钮，等准备完成后启动；现有 Launch.ps1 作为兼容入口转交软件。F3/F8/F9/F11 及原 ESP/连跳逻辑不变。
- --smoke-test 与 --probe 保持只做测试/诊断，不启动安装管理。游戏识别限制为选定安装目录，不能匹配其他 Half-Life 安装。
- 使用真实临时游戏目录和自建测试进程验证完整生命周期、崩溃、延迟清理、重启等待及恢复冲突；完整 Debug/Release 回归后打包 1.3.0。

实现选择：复用已有 PowerShell 安装与恢复逻辑，界面通过状态文件接收进度；本版无需将文件事务重写为 C++，也无需加载中的 DLL 强制卸载。
