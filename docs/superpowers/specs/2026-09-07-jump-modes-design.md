# 1.4.0 跳跃模式设计

用户已要求在发布 1.3.0 后继续实现六种互斥模式，并提供 GitHub 与赛盟作为动作参考。沿用 F3 开关和按住空格触发；默认选择原自动跳跃、总开关关闭。不恢复存点 / 回点。

| 模式 | 本版动作 |
| --- | --- |
| 自动跳跃 | 沿用落地释放跳跃锁存，方向完全手动 |
| AutoBhopJump | 连跳 + 空中自动左右摆角及对应侧移 |
| LongJump | 每次按住空格完成一次起跳与四段左右空中变向，落地不续跳；松开可中止 |
| MCJ | 三次短按蹲的小跳准备后，接一次 LongJump；每次空格触发一组 |
| BhopJump | 连跳，空中根据用户视角转向自动配合 A / D 方向，不自动转视角 |
| 狗跳 | Double Duck：短蹲、松蹲、再次蹲至落地，按住空格循环 |

软件显示每种模式动作说明，模式偏好写入 INI。模式切换、F3 关闭、松空格、切后台、死亡 / 水中 / 梯子 / 非本地对局、切图、控制过期均清空序列状态，不在后台继续一组动作。

保留现有 Metamod 会话边界。新 JumpAssist 对本地主机的 SDK movement command 进行时序处理，仅修改 jump/duck 命令位、跳跃锁存、水平输入和自动模式的 yaw；速度、位置、重力交给游戏物理。自动摆角通过本地主机的 fixangle 同步到视图。不会调用系统按键注入，不改变 SPACE / CTRL / A / D 绑定。存在与既有服务端连跳相同的客户端预测校正限制，必须在说明中写明尚未实际游玩验收，不承诺跳跃距离或速度数值。

控制协议升级到 v2，保持 40 字节大小，在保留区加入 mode / generation；旧版及越界模式拒绝。generation 用于同一模式重新触发和软件重启后的状态重置。原 ESP 协议保持不变。

参考只用于动作语义，自行实现状态机；不复制无授权声明的参考项目源码。源码参考固定提交 fcf5751613098a7cb446a74a42bd4b80bb964203：
