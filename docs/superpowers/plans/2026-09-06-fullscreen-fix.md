# 全屏透视修复与打包

用户要求修复全屏显示后打包发布。连跳 / KZ 范围仍待选择，不纳入本次发布。

根因：当前 EXE 使用桌面分层窗口绘制，独占全屏 OpenGL 交换链不保证显示桌面覆盖窗口。

已核对本机 `hw.dll` 导入 `SDL_GL_SwapWindow`，`SDL2.dll` 导入 `GDI32!SwapBuffers`。通过已经加载的本地插件在交换缓冲前绘制，即可让标记进入游戏画面。

## 约束

- 不修改游戏 EXE 和原始 DLL 文件；导入表调整只发生在已授权加载的插件生命周期内，无远程注入或私有地址偏移。
- SDK 快照 v1 保持不变，独立控制通道携带协议版本、游戏 PID、时间戳及配置；500ms 过期停止绘制。
- 保留 F8 / F9 / F11、变色 HP 数字与单机条件；不重新加入血条。
- 在全屏和窗口模式均优先游戏内绘制，以同一个画面数据路径验证。OpenGL 不可用时报告原因。
- 退出或切图后不得残留；保存并恢复 GL 状态，包括当前着色器和帧缓冲，避免破坏新版 GoldSrc 的 shader 渲染。
