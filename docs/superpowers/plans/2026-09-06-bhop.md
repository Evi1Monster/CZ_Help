# 自动连跳实现计划

> 使用 executing-plans 在当前任务逐项实施。根代理实现，独立子代理复核移动字段及完整集成。

**目标：** 1.2.0 只新增独立 F3 开关与按住空格自动连跳。

**架构：** 独立控制通道传送开启/空格状态，Metamod PM_Move 前为有效本地落地玩家清除旧跳跃锁存。原 ESP 渲染和通道保持兼容。

**技术栈：** Win32 x86/C++17、Valve SDK、Metamod、CMake/CTest、PowerShell。工作目录不是 Git 仓库，不创建分支或提交；dist 中保留 1.1.1。

## 1. 核心与通道

文件：shared/bhop_control.h、plugin/bhop.h/.cpp、plugin/bhop_tests.cpp、tests/bhop_channel_tests.cpp、CMake。

- [x] 为 `bool ApplyBhop(playermove_t*,bool authorized,bool spaceHeld)` 添加空实现与 SDK 夹具，确认落地连跳测试失败再实现。最终落地输入采用当前 flags，非 onground 旧计算值。
- [x] 覆盖松开、空中、水中、梯子、死亡、旁观、冻结、禁用、客户端、非本地玩家、其他按钮与速度保持。实现仅 `oldbuttons &= ~IN_JUMP`。
- [x] BhopControl 40字节包含 magic/version/bytes/pid/timestamp/flags/reserved；enabled=1、spaceHeld=2，验证150ms时效和未知标志。BhopStatus同大小发布能力、会话和诊断计数。
- [x] 使用现有 RenderMailbox 模板与独立 BhopControl/BhopStatus 名称，测试真实映射读取与只读端拒绝写入。

运行 `cmake --build build --config Debug --target bhop_tests bhop_channel_tests`，分别运行产物确认红绿循环。
