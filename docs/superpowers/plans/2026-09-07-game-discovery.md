# 从运行中的零点行动识别安装目录

目标：先开游戏、后开辅助时，无需修改 INI 即可找到安装目录。

方案：启动参数优先；否则通过 Windows 本地 WMI 查询 hl.exe 的 PID 和命令行，确认 -game czero，再从进程句柄读取 EXE 完整路径，验证游戏文件。使用唯一目录；多个目录时优先配置匹配项，否则提示使用 --game-path。无候选时使用现有配置。识别结果显示在面板并保存到配置。只在启动时选择一次，避免安装和清理过程中切换目标。

仅按文件名识别容易误认 CS 1.6；扫描 Steam 库不能确定用户正在玩的副本。本次采用运行进程识别，不新增全盘扫描。进程不可读或 WMI 不可用时给出提示并保留配置回退。

游戏未加载插件时，仍由现有会话管理等待游戏退出，自动配置后由用户重新启动；不增加热加载或自动结束游戏。
