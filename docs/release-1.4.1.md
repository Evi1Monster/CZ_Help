# CZ Help 1.4.1 使用说明

跳跃辅助精简为 **自动跳跃** 和 **BHopJump** 两个单选项。透视功能、变色 HP 数字和 F8 / F9 / F11 保持原样。

## 使用

1. 退出旧辅助和游戏，完整解压 ZIP，运行根目录 **CZ_Help.exe**。
2. 等待 **准备就绪 · 等待游戏启动**，再点击“启动本地游戏”或自行启动游戏。
3. 选择跳跃模式，按 **F3** 开启，然后在游戏中 **按住空格**执行，松开停止。
4. 关闭辅助后自动清理；游戏尚未退出时，等待游戏退出后恢复原文件。

请保留 `bin`、`scripts` 和 `third_party` 文件夹，正常使用无需手动安装或卸载插件。

## 保留的跳跃模式

| 模式 | 行为 |
| --- | --- |
| 自动跳跃 | 落地自动继续跳跃，移动方向和视角由你控制 |
| BHopJump | 连跳；空中根据你手动转视角的方向自动配合左右侧移 |

模式会记住，跳跃与透视总开关每次启动默认关闭。原 AutoBhopJump、LongJump、MCJ、狗跳及自动摆角功能已删除。

`CZ_Help.ini` 的 `[Movement] Mode=0` 对应自动跳跃，`Mode=4` 对应 BHopJump，兼容 1.4.0 原编号。旧配置选中了已删除模式时，自动回退到自动跳跃并显示提示；选择任一保留模式即可保存新偏好。

## 保持不变

- F3：跳跃辅助开关；F8：透视开关；F9：方框开关；F11：变色 HP 数字开关。
- 默认游戏目录：`D:\SteamLibrary\steamapps\common\Half-Life`，通过 `[Game] Path` 修改后重启生效。
- 运行时自动配置，显示等待 / 就绪；退出或崩溃后自动恢复，有冲突时保留原文件和备份。
- 仅本地 `sv_lan 1`、单真人、存活、第一人称适用。空格保持 `+jump` 绑定。切后台、松空格、关闭、水中、梯子、死亡或非本地对局时停止辅助。

本版经过代码、界面和安装清理回归；没有重新操作真实对局验证跳跃手感。BHopJump 的服务端指令可能出现客户端预测校正。详细验证见 `source/docs/verification.md`。
