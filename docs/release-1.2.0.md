# CZ Help 1.2.0 使用说明

适用于 Windows 上 Steam《CS 零点行动》的普通本地 BOT 对战。支持 OpenGL 全屏与窗口模式，新增按住空格自动连跳。

## 安装与启动

1. 将整个 ZIP 解压到固定目录，退出游戏和旧版辅助程序。
2. 双击 **1-Install-or-Update.cmd**，默认更新到 `D:\SteamLibrary\steamapps\common\Half-Life`，保留初次安装前的恢复备份。
3. 双击 **2-Launch.cmd**，进入本地 BOT 对局并加入队伍。启动器沿用游戏保存的全屏 / 窗口设置。
4. 按 **F3** 开启连跳，然后按住 **空格**。每次落地后会自动再次跳跃；松开空格停止，再按 F3 关闭。也可勾选面板的“自动连跳（按住空格）”。

连跳每次启动辅助时默认关闭，独立于透视。需要默认的 `bind SPACE +jump` 绑定，辅助程序保持运行。保持原游戏速度、重力和跳跃规则，不包含存点、回点或其他 KZ 功能。

## 快捷键

| 功能 | 按键 |
| --- | --- |
| 自动连跳开关 | F3，开启后按住空格 |
| 透视总开关 | F8 |
| 方框开关 | F9 |
| 血量数字开关 | F11 |

HP 只显示随血量变色的数字，没有血条。所有开关键长按只切换一次，并且只在游戏前台响应。退出辅助、切后台、死亡、旁观、非本地会话或控制数据过期后，连跳停止生效；水中、梯子和冻结状态保留游戏原操作。

## 更新与设置

- 本版需要同时使用新版 EXE 和插件 DLL；如果面板显示“连跳等待插件更新”，退出游戏后运行安装或更新，再重启。
- 设置文件为 `bin\CZ_Help.ini`。`BhopToggle=114` 对应 F3；F8 / F9 / F11 仍是 119 / 120 / 122。旧设置可复制过来，缺失的新键默认 F3；若冲突则只禁用连跳快捷键，仍可勾选。
- 本地对局需 `sv_lan 1`、只有一名真人、玩家存活且第一人称。连跳本身不要求存在敌方 BOT，透视仅标记存活敌方 BOT。
- 其他目录使用 `scripts\Update.ps1 -GamePath '你的 Half-Life 目录'`，启动脚本也支持 `-GamePath` 和 `-Windowed`。
- 游戏控制台 `meta list` 查看插件版本；`cz_help_status` / `cz_help_dump` 查看透视数据。外部 `bin\CZ_Help.exe --probe 游戏PID` 可读取连跳能力和触发诊断。

## 验证范围

上一版全屏透视和 F8 / F9 / F11 已由用户确认正常。最终 Debug / Release 构建及测试各 **9/9** 通过，安装与更新恢复测试通过。新增连跳使用真实 SDK 类型、命名共享通道和插件接口做自动回归；测试覆盖落地、松键、关闭、控制过期、玩家身份、水中、梯子、死亡等条件，并检查速度和其他指令未改变。具体记录见 `source\docs\verification.md`。

连跳实际游戏画面及客户端预测手感尚未实机验收；服务端移动调整可能产生短暂的预测校正。没有修改游戏速度或重力来掩盖该差异。

## 卸载与源码

退出游戏后双击 **3-Uninstall.cmd**。请保留游戏内 `czero\addons\cz_help\install-state.json`，它保存初始恢复记录；若后续自行修改过相关文件，脚本会提示冲突。

`source` 包含本版源码、构建脚本和依赖许可。构建需要 Visual Studio 2022 C++ 桌面开发组件、Windows SDK、CMake 3.20 以上，运行 `source\scripts\Build.ps1 -Configuration Release`。
