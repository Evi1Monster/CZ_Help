## 1.1.1 宽屏投影修复 · 2026-09-06

用户后续实机反馈：**全屏可用，F8 / F9 / F11 正常**；另报告 BOT 偏离准星时方框和 HP 偏移。因此 1.1.0 下方“视觉验收未完成”仅描述当时自动操作的限制，已有用户确认作为补充。

定位：当前游戏保存 `gl_widescreen_yfov=1`，实际画面 1920×1080。旧投影把服务端基准 90° 当成最终水平 FOV，导致偏离中心的距离放大 4/3。按当前 Steam 引擎的规则，宽高比严格大于 1.5 且宽屏开关非零时换算水平 FOV（16:9 的 90°基准对应 106.2602°）。阈值和公式来自本机磁盘引擎的只读分析，见 `widescreen-projection-analysis.md`。

实现：每帧通过引擎 cvar 接口读取当前开关，按当前渲染尺寸转换基准 FOV；游戏内绘制和桌面回退使用同一个计算函数。不修改用户的视频设置。快照和控制通道保持 v1 大小，渲染状态利用原保留字段传递模式。

回归：新投影用例在修复前出现 5 项预期失败；覆盖左右离中心位置、垂直位置、中心不漂移、开关、4:3、窄屏、3:2 边界、俯仰 / 偏航及开镜。新增真实 320×180 WGL 测试，以独立 `glFrustum` 投影角色角点，核对方框四边与 HP 文字位置，分别测试宽屏开关。

本次不再控制游戏；宽屏偏移修复的实际 BOT 画面仍待用户复核。

最终验证：x86 Debug / Release 全量构建及 CTest 均 **7/7** 通过，包含新增的真实宽屏像素对照。HP 字形的实际着色边界与文字原点不同，测试按首字符 `1` 的 2 px 左边距校验，保留独立参考投影与 2 px 光栅化容差。

已在游戏退出后更新安装到 1.1.1；安装 DLL 与最终 Release DLL 的 SHA-256 均为 `CDA24F6A04A3173200361AE7CBA661EF0E60FD287E24BDB886CFEBBE597DB62B`。EXE 文件版本及产品版本均为 1.1.1，原卸载备份保留。
