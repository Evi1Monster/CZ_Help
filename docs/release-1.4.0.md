# CZ Help 1.4.0 使用说明

本版加入六种互斥的跳跃模式，保留 1.3.0 的自动配置、退出清理，以及全屏方框 / 变色 HP 数字。

## 使用

1. 退出旧辅助和游戏，将 ZIP **完整解压**，双击根目录 **CZ_Help.exe**。
2. 出现 **准备就绪 · 等待游戏启动** 后，点击“启动本地游戏”。
3. 在面板选择一种跳跃模式，按 **F3** 开启，然后在本地 BOT 对局中按住 **空格**。松开立即中止，F3 再按关闭。
4. 关闭辅助自动清理；若游戏仍运行，功能停止，隐藏清理进程等游戏退出后恢复原文件。

无需手动安装插件，需保留 `bin`、`scripts`、`third_party` 文件夹。初次配置 / 更新遇到游戏未退出时，界面显示等待状态，退出游戏后自动继续。

## 六种单选模式

| 模式 | 动作 |
| --- | --- |
| 自动跳跃 | 原来的落地自动续跳，方向和视角手动 |
| AutoBhopJump | 连跳，同时在空中自动左右摆动视角和侧移 |
| LongJump | 自行助跑后触发一次起跳及四段空中变向；落地不续跳 |
| MCJ | 自行助跑后执行三次短蹲小跳准备，再接一次 LongJump |
| BhopJump | 连跳；根据你手动转动视角的方向，配合左右侧移 |
| 狗跳（Double Duck） | 短蹲、松蹲、再次蹲至落地，按住空格持续循环 |

LongJump / MCJ 每次空格执行一组，松开后重新按住可再执行。切换模式会清空当前动作。模式会记住，F3 和透视总开关每次启动均关闭。

自动模式只辅助动作，保留原游戏物理，**不保证距离、速度或同步率**。新模式已经过指令、状态切换和界面自动测试，**真实对局的效果、客户端预测校正和操作手感尚未验收**。

## 按键与设置

F3：跳跃总开关；F8：透视；F9：方框；F11：变色血量数字。仍没有血量条。

默认游戏目录 `D:\SteamLibrary\steamapps\common\Half-Life`。EXE 旁 `CZ_Help.ini` 的 `[Game] Path` 可修改目录，重启生效；`[Movement] Mode` 为 0..5，顺序与上表一致，也可直接点击单选按钮。快捷键设置后点击“重新加载设置”。

空格需绑定 `+jump`。仅本地 `sv_lan 1`、单真人、存活且第一人称可用；切后台、关闭、松空格、水中、梯子、死亡、旁观或非本地对局时停止。没有存点和回点功能。

自动恢复的冲突与额外诊断入口见 `source/docs/release-1.3.0.md`，完整验证范围见 `source/docs/verification.md`。
